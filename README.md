This is an add-on package to OpenKJ 2.50 or greater from the DJ-Joel repository.  This will not work with legacy OpenKJ.

What this package includes:

+  remote requests with key change option
+  chat with KJ (didn't see your song, ask the KJ)
+  view singer rotation
+  create account
+  save favorite songs
+  QR code creation to point singers to the remote request service

+  Self hosted, stand alone.  No monthly fees.


What you must have:
A Windows PC
OpenKJ 2.50+


Download this installer from the releases section
Run the installer

During the installation you will be asked some questions,be sure not to skip them.
